# Water Tracker Bot

Telegram-бот для учёта воды. Задай дневную цель, записывай воду кнопками +500 мл, +1 л или введи свой объём. При достижении цели бот отправит сообщение.

## Запуск на macOS

Нужен Python 3.11 или новее. Сторонние пакеты не требуются.

1. Получи токен бота через [@BotFather](https://t.me/BotFather).
2. В папке проекта выполни в zsh:

   ```zsh
   read -rs 'TELEGRAM_BOT_TOKEN?Токен от BotFather: '
   export TELEGRAM_BOT_TOKEN
   python3 water_bot.py
   ```

3. Открой личный чат с ботом и нажми «Старт».

Данные хранятся в SQLite рядом со скриптом. День начинается в полночь по Тюмени. Часовой пояс можно изменить переменной окружения `WATER_BOT_TZ`. Бот отвечает, пока скрипт запущен и доступен Telegram API.
